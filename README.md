# Практикующий юрист — демонстрационный сайт

Демонстрационная концепция юридической практики на основе действующего сайта и предоставленного заказчиком перечня экспертиз.

## Состав проекта
Главная, каталог юридических услуг с семейными спорами, единый раздел «Независимая экспертиза» с двумя основными направлениями (строительная и автотехническая), дополнительными экспертными исследованиями в раскрывающемся блоке, отдельные страницы, раздел «О юристе», контакты, черновик политики персональных данных. Адаптивная вёрстка, мобильное меню, демо-форма без отправки.

## Локальный запуск
`python -m http.server 8080` и открыть `http://localhost:8080/`. Сайт статический, сборка не требуется.

## Важные условия
- Публичное оформление заменено на «Практикующий юрист», знак-монограмма и прежнее название удалены из видимых элементов.
- Прайс и все опубликованные цены убраны, а три исключённые услуги удалены из демопроекта.
- Работа только дистанционно, без привязки к одному городу. Встречи и выезды не заявляются.
- Контакты мессенджеров: Telegram `https://t.me/TATI_JURIST`, MAX — ссылка из предоставленного заказчиком скриншота; перед коммерческим запуском подтвердить корректность открытия обеих ссылок.
- Городской номер +7 (391) 214-49-00, мобильный +7 (933) 338-55-67; действующий e-mail необходимо подтвердить.
- Фотография юриста уже размещена по предоставленному снимку. ФИО, образование, квалификация и стаж подлежат подтверждению перед коммерческим запуском.
- Экспертные услуги взяты из предоставленного документа; сведения о фактическом исполнителе, правовой форме и сроках требует подтверждения.
- Форма не отправляет и не сохраняет данные. Политика обработки персональных данных — черновик.
- Сохранены `noindex,nofollow` и `robots.txt` с `Disallow: /` до отдельной SEO-приёмки.
- Действующий домен заказчика не менялся, другие репозитории не затрагивались.
