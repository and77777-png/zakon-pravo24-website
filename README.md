# ZAKON / PRAVO — премиальный демонстрационный сайт

Первая многостраничная концепция редизайна [zakon-pravo24.ru](https://zakon-pravo24.ru/) для согласования с клиентом.

## Запуск

Нужен только статический HTTP-сервер. Из директории проекта: `python -m http.server 8080` и открыть `http://localhost:8080/`. Также можно открыть `index.html` как локальный файл.

## Состав

Главная, каталог услуг, 8 посадочных страниц направлений, цены, о компании, контакты, черновик страницы персональных данных. Адаптивный интерфейс, динамическое мобильное меню, плавные переходы, уважение `prefers-reduced-motion`, демо-форма без отправки, корректные `mailto` и `tel`. Без CMS и сборки.

## Важно перед запуском

- ДЕМО-сайт содержит `noindex,nofollow` и `robots.txt` с `Disallow: /`. **Не удалять без утверждённой SEO-приёмки.**
- Формы не отправляют информацию и не сохраняют персональные данные. Подключить обработку на российском VPS после утверждения политики, согласий и защиты.
- Цены получены из исторически опубликованного прайса. Не считать подтверждёнными на 2026 год.
- Нужны подтверждение официального названия, логотипа, реквизитов, адреса, команды, цен, условий консультации, направления услуг.
- Перед переключением домена — карта старых URL, 301 redirect, canonical, sitemap, Yandex Webmaster и проверка почтовых DNS-записей.
- Домен действующего сайта не затронут.
- CSS использует системные шрифты с локальными fallback: у посетителя нет зависимости от внешних шрифтов/CDN.
