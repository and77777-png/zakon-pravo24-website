# Практикующий юрист — демонстрационный сайт

Демо-концепция сайта юридической практики в Красноярске на основе материалов действующего сайта и предоставленного заказчиком перечня видов экспертиз.

## Просмотр

Статические HTML, CSS, JS. Для локальной проверки: `python -m http.server 8080`, затем `http://localhost:8080/`.

## Состав

- Главная: услуги, подход, контакты, блок о практикующем юристе с местом под фото
- Каталог юридических услуг и отдельный каталог из 7 экспертных направлений
- Подробные страницы по строительной, автотехнической, оценочной, землеустроительной, экономической/бухгалтерской/товароведческой, почерковедческой экспертизам и рецензиям
- Основные юридические разделы, контакты, раздел «О юристе», демонстрационная информация о персональных данных
- Мобильное меню и адаптивная верстка

Прайс и разделы, исключённые заказчиком, в этой версии не публикуются. Новый мобильный: +7 (933) 338-55-67, городской +7 (391) 214-49-00.

## Безопасность демо

- `noindex,nofollow` и `robots.txt` с `Disallow: /` остаются до разрешения заказчика на публикацию и SEO-приёмки.
- Формы в демоверсии не отправляют и не сохраняют персональные данные.
- Профессиональное фото, полное имя юриста, подтверждение стажа и сведения о юрлице необходимо согласовать.
- Правовая база и сроки отдельных исследований взяты из клиентского документа и требуют юридического/фактического согласования перед коммерческим запуском.
- Рабочий домен заказчика не изменён.

## Деплой

Статический GitHub Pages из ветки `main` после merge. Никаких сторонних сервисов, аналитики, CRM или отправки форм не подключено.
