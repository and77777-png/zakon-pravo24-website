# Практикующий юрист — сайт для дистанционных обращений

Статический сайт юридической практики. Контактные действия ведут напрямую в Telegram, MAX или телефон, без отправки заявок через сайт.

## Состав проекта
Главная, каталог юридических услуг с семейными спорами, единый раздел «Независимая экспертиза» с двумя основными направлениями (строительная и автотехническая), дополнительными экспертными исследованиями в раскрывающемся блоке, отдельные страницы, раздел «О юристе», контакты, черновик политики персональных данных. Адаптивная вёрстка, мобильное меню, прямые кнопки обращения в Telegram, MAX и телефон.

## Локальный запуск
`python -m http.server 8080` и открыть `http://localhost:8080/`. Сайт статический, сборка не требуется.
